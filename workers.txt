# Packages the orb-agent entrypoint pip-installs at container start
# (pointed to by INSTALL_WORKERS_PATH). Sources can be PyPI, a tar.gz, or a
# local folder containing pyproject.toml.
#
# Local development: mount this repo at /opt/orb and install from the repo root.
# Production: prefer a pinned published version so Orb does not float on
# pyproject lower bounds the way `uv.lock` pins CI/dev.
.
